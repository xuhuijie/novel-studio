# 人物小传模板

> 基于《青山》创作理念设计的人物小传模板，帮助创作者塑造有深度的立体人物。

---

## 模板使用说明

**适用对象**：
- 主角
- 主要配角（戏份超过20%的人物）
- 关键配角（推动重要情节的人物）

**填写原则**：
- 每个要素都要有具体细节，避免空洞
- 重点挖掘矛盾与冲突
- 保持人物逻辑一致性

## 使用建议

1. **主角**：必须填写完整版小传
2. **主要配角**：填写完整版，重点填写诉求、矛盾、抉择
3. **关键配角**：使用快速版小传
4. **次要配角**：只填写核心身份、诉求、结局即可

**更新原则**：
- 随着剧情推进，持续更新人物状态
- 如果人物行为偏离小传，检查是否符合人物逻辑
- 如需修改，确保前后一致性
