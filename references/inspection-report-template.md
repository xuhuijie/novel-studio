# 章节逻辑检验报告模板

## 标准格式

```markdown
## 第N章《{章节名}》逻辑检验报告

### ✅ 通过项
- [因果链] {具体说明}
- [人物一致性] {具体说明}
- [时间线] {具体说明}
- [世界观] {具体说明}
- [伏笔] {具体说明}

### ⚠️ 疑问项
- [维度] {问题描述}
  - 可能原因：{分析}
  - 建议修正：{具体建议}
  - 状态：待处理/已处理（第X章已修改，{具体内容}）

### ❌ 问题项
- [维度] {严重问题}
  - 违反前文：{引用}
  - 当前问题：{描述}
  - 必须修正：{方案}
  - 状态：待处理/已处理

### 🔴 剧情冲突预警
- [冲突类型] {描述}
  - 严重程度：🔴 高 / 🟡 中 / 🟢 低
  - 影响范围：{影响的章节/伏笔}
  - 建议处理：{方案}
  - 状态：待处理/已处理（第X章已修改）

### 总结
{整体评价}，{是否需要修正}
```

## 状态标记规范

| 状态值 | 含义 | 何时使用 |
|--------|------|----------|
| `待处理` | 问题已发现但未修复 | 新写章节的检验报告 |
| `已处理（第X章已修改，{内容}）` | 问题已在指定章节修复 | 修复完成后的更新 |
| `已忽略（理由：{原因}）` | 确认不是问题，主动忽略 | 误报或可接受的设计选择 |

## 常见疑问项类型

### 人物功能性过强
- 症状：某配角一次性提供了过多关键信息
- 修复：降低其能力边界，改为"知道一部分，推断另一部分"
- 示例：柳青鸢只识得腰牌制式，暗记是师父笔记中提到但未完全破解

### 配角独立性不足
- 症状：配角仅作为信息传递工具人
- 修复：给配角安排独立情节线，与主线形成镜像
- 示例：赵横母亲生病需要钱→赵横的道德困境→与陈力主线形成对照

### 信息密度过高
- 症状：单章内揭露过多关键信息
- 修复：将信息拆分到多章，逐步揭示
- 示例：老瘸子只提供"断耳腰牌"和"铁勒部女人"，"王贵送腰牌"改为陈力自行推断

### 时间线矛盾
- 症状：章节内时间跨度不清晰或前后矛盾
- 修复：明确标注时间点，检查跨章时间线一致性
